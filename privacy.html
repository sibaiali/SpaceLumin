Privacy Policy

Last updated: February 2026

1. About This Game

Lumin Flow: Utopia Run ("the Game") is a browser-based space survival game published by Ali (the "Developer"). The Game is available as a Progressive Web App and via the Google Play Store as a Trusted Web Activity.

2. Data We Collect

The Game collects no personal data. All game state (high scores, upgrade progress, settings) is stored exclusively on your device using the browser's localStorage API. This data never leaves your device and is never transmitted to any server.

3. What Is Stored Locally

  • High score and diamond count
  • Archive Shards (meta-progression currency)
  • Purchased upgrades
  • Audio and display settings

You can clear this data at any time by clearing your browser's site data or using the Android App's "Clear Data" option in Settings.

4. Analytics & Third-Party Services

The Game does not use Google Analytics, Firebase, Crashlytics, or any third-party analytics SDK. No advertising SDKs or in-app-purchase SDKs are included.

The Game loads the following external resources at runtime:

  • three.js (3D rendering) – loaded from cdnjs.cloudflare.com
  • Tone.js (audio) – loaded from cdnjs.cloudflare.com
  • Google Fonts (Cinzel, Inter) – loaded from fonts.googleapis.com

These requests are subject to each provider's respective privacy policy. No game data is shared with these providers.

5. Permissions

The Android/TWA package of the Game requests no special Android permissions. It does not access your camera, microphone, contacts, location, or any other device sensor.

6. Children's Privacy

The Game does not knowingly collect information from children under 13. Since no data is collected at all, the Game is safe for players of all ages.

7. Changes to This Policy

If we make material changes to this policy, we will update the "Last updated" date above. Continued use of the Game after changes constitutes your acceptance.

8. Contact

Questions about this policy? Open an issue on the project repository or email the developer directly at the address listed on the Google Play Store listing.

9. Adaptive AI & On-Device Processing

Lumin Flow uses on-device algorithms to adapt game difficulty to your play style. These systems analyse patterns in your in-game inputs — movement speed, shooting accuracy, reaction time — entirely within your device's browser. No input data is recorded beyond your current session, stored permanently, or transmitted anywhere.

The techniques used include kernel similarity methods, Markov chain state prediction, and exponential smoothing. All computation is local and ephemeral. The game does not use any external AI API, cloud inference service, or third-party machine-learning platform. Everything runs inside your browser tab.

10. Developer Debug Overlay

A developer-only diagnostic panel ("Ghost Console") is included in the game code. It is permanently disabled on any domain other than localhost — it cannot activate in the Play Store build or on the live website. It collects no data and writes nothing to disk.
